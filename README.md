# Суд над морковкой 🥕

Нативная офлайн-игра для Android: абсурдный овощной суд на **Kotlin + Jetpack Compose**. Никакого сервера, авторизации, API и разрешения на интернет.

## Установка

Нужен Android 8.0 (API 26) или новее. Скачайте APK, откройте его на телефоне и разрешите установку из выбранного источника. Это debug-сборка для знакомства с игрой.

**GitHub Actions:** откройте [Android APK](https://github.com/SHADrussed/carrot-judjement/actions/workflows/android.yml), выберите успешный запуск → **Artifacts → carrot-court-debug-apk**. Распакуйте ZIP и установите `app-debug.apk`. Артефакт хранится 30 дней; новый запуск создаёт новый APK. Для загрузки Actions artifacts требуется вход в GitHub.

## Что внутри

- Пиксельный зал суда, Картофель-судья, Брокколи-прокурор, Майонез-адвокат и обвиняемая Морковка. Графика рисуется локально через Compose Canvas.
- 52 обвинения, 52 реплики защиты, 36 показаний от 9 свидетелей, 40 обычных и 4 секретных приговора, 12 событий-пасхалок.
- Моргание, прыжки, тряска и смена эмоций, конфетти при решении суда.
- Программные звуки (кнопка отключения вверху), вибрация на приговоре. Звуки зависят от громкости мультимедиа, вибрация — от оборудования и настроек Android.
- Архив: общее число дел, виновных, оправданных и уникальных тайных приговоров; последние 50 решений.
- Справочник с найденными редкими фразами и закрытыми карточками оставшихся секретов.
- Состояние дела, статистика, секреты и звук сохраняются в локальных SharedPreferences. Поворот экрана и перезапуск не начинают дело заново. Удаление приложения / очистка данных удаляют прогресс. Облачное резервное копирование отключено.
- Вертикальная компоновка с прокруткой, безопасные отступы системных панелей, поддержка большого шрифта.

## Правила этого беспредела

Обвиняйте, защищайте и вызывайте свидетелей в любом порядке. Последовательные реплики одной категории не повторяются. При каждом выступлении вероятность события составляет 20%, а вероятность тайного приговора — 12%. Решение случайно: это юмористическая игра, не симулятор права. Редкие находки собираются автоматически, повторные находки не увеличивают коллекцию.

Одно дело получает один приговор. После этого выступления блокируются до «Нового бреда». Эта кнопка открывает новое дело, сохраняя архив; незавершённый процесс не добавляется в статистику.

## Сборка

Требования: JDK 17 (проверено также на JDK 21), Android SDK Platform 35, Build Tools 35.0.0. Gradle 8.9 загружается включённым wrapper.

1. Откройте проект в Android Studio либо задайте `ANDROID_HOME` / `sdk.dir` в локальном `local.properties`.
2. Выполните:

```sh
./gradlew assembleDebug
./gradlew testDebugUnitTest lintDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Первый запуск сборки требует интернет для инструментов и зависимостей; установленное приложение полностью офлайн.

## Структура

- `data/AbsurdCatalog.kt` — авторские реплики и стабильные идентификаторы секретов.
- `data/CourtEngine.kt` — чистая логика игры с управляемым генератором случайных чисел.
- `data/CourtStore.kt` — локальное сохранение единым JSON-снимком.
- `CourtViewModel.kt` — состояние Compose и действия.
- `ui/PixelCourt.kt` — процедурный пиксель-арт и анимации.
- `ui/CourtApp.kt` — суд, архив, справочник и эффекты.
- `app/src/test/` — тесты каталога, уникального подсчёта, случайных реплик и длительной игры.
- `.github/workflows/android.yml` — сборка APK, unit-тесты, Android Lint и артефакты.
